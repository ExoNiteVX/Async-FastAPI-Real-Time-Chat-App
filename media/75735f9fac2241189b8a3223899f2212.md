# Nordveil commercial website

Django REST backend with a static frontend for the Nordveil storefront.

## Setup

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cd BackEnd
../.venv/bin/python manage.py migrate
../.venv/bin/python manage.py createsuperuser
```

The repository already includes a development database. Use the existing virtual environment when available.

## Run locally

Start the backend from the repository root:

```bash
.venv/bin/python BackEnd/manage.py runserver 127.0.0.1:8000
```

Serve the frontend in a second terminal:

```bash
python3 -m http.server 5501
```

Open [http://127.0.0.1:5501/frontend/](http://127.0.0.1:5501/frontend/) for the storefront and [http://127.0.0.1:8000/admin/](http://127.0.0.1:8000/admin/) for administration. Use a plain static server for the frontend because live-reload injection can corrupt standalone SVG partials.

The frontend calls `http://127.0.0.1:8000/api` by default. To use another backend, set `window.API_BASE_URL` before `js/main.js` loads.

## Useful routes

- `GET /api/products/` catalog listing
- `GET /api/products/<slug>/` product detail
- `GET /api/categories/` categories
- `GET /api/cart/` current session cart
- `POST /api/cart/items/` add `{ "product": "slug", "qty": 1 }`
- `/admin/` products, orders, users, reviews, and analytics dashboard

## Checks

```bash
cd BackEnd
../.venv/bin/python manage.py check
cd ..
node --check frontend/js/main.js
```
